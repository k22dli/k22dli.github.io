Политика конфиденциальности

Эта политика описывает личное приложение PRO+ DR Backup и его информационный сайт. Приложение предназначено для резервирования данных самого владельца #безнервов / PRO+.

Какие Google-данные доступны

Процесс работает с содержимым и метаданными выбранных документов, таблиц и файлов Google Drive, включая их названия, идентификаторы, время изменения и сведения, необходимые для проверки копий и разрешённого места хранения.

Настраиваемый OAuth-путь запрашивает drive.readonly для чтения файлов и drive.file для создания и управления файлами резервных копий приложения. Разрешение drive.readonly технически позволяет читать доступные авторизованному аккаунту файлы Drive; рабочий процесс использует выбранные владельцем источники. drive.file ограничивает запись файлами, созданными приложением или предоставленными ему владельцем.

Приложение не запрашивает доступ к Gmail, Google Contacts, Google Calendar или платёжным данным. Оно не меняет исходные документы в рамках резервирования и не расширяет права доступа к ним.

Зачем и где обрабатываются данные

Единственная цель доступа — создать приватную резервную копию, проверить её целостность и возможность восстановления, а также обслуживать разрешённый владельцем архив копий.

Обработка выполняется в приватной среде автоматизации GitHub Actions и, при ручной проверке, на компьютере владельца. Копии Google-данных сохраняются в закрытых хранилищах Google Drive и/или приватного репозитория GitHub в соответствии с выбранным маршрутом резервирования. При проверке восстановления копии скачиваются в локальную рабочую среду. Поэтому данные могут передаваться из Google в GitHub и на компьютер владельца.

Google и GitHub выступают поставщиками инфраструктуры и обрабатывают данные в рамках своих условий. В приложении нет публичной выдачи копий, передачи данных рекламодателям, продажи данных или использования Google-данных для обучения общих моделей искусственного интеллекта. Человеческий доступ ограничен владельцем и явно разрешёнными им участниками его закрытой инфраструктуры.

Использование и передача данных, полученных через Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

Защита и срок хранения

Передача к Google и GitHub идёт по HTTPS. Доступ к резервным копиям ограничивается правами закрытых хранилищ. OAuth-токены и другие учётные данные хранятся отдельно в защищённом хранилище секретов автоматизации; они не включаются в публичный сайт, исходный код сайта или резервные архивы.

Дополнительное шифрование архивов самим приложением не заявляется. Сохранность зависит также от защиты аккаунтов владельца, его компьютера и инфраструктуры поставщиков.

Срок хранения определяется политикой резервирования владельца: сохраняются дневные, недельные и месячные копии, а также защищённые контрольные точки. Удаление старых управляемых копий допускается только после проверки актуальной копии и в пределах этой политики. Владелец может остановить автоматизацию и удалить свои копии вручную.

Отзыв доступа и удаление

Чтобы прекратить Google-доступ, откройте Подключения к сторонним приложениям и сервисам в Google-аккаунте, выберите PRO+ DR Backup и удалите его подключение. Отзыв доступа останавливает дальнейший доступ по отозванным разрешениям, но не удаляет ранее созданные копии.

Для полного удаления владелец отдельно останавливает соответствующий процесс резервирования, удаляет его OAuth-учётные данные из приватного хранилища секретов и удаляет копии из Google Drive, приватного GitHub-хранилища и локальных папок. Данные в корзине, истории версий или хранилищах поставщика могут сохраняться до их удаления или истечения сроков хранения у поставщика.

Информационный сайт и контакт

Этот сайт не содержит форм входа, не собирает Google-данные и не использует собственную аналитику, рекламные скрипты или собственные cookie. Хостинг GitHub Pages может обрабатывать обычные технические данные HTTP-запросов по политике GitHub.

Ответственный за приложение — владелец аккаунта k22dli. Для вопросов о Google-доступе используйте адрес User support email, отображаемый в сведениях о приложении на экране разрешений Google. Приложение используется самим владельцем, который управляет источниками, копиями и сроками хранения.

При изменении обработки данных владелец обновляет эту страницу и дату её действия. См. также описание приложения и условия использования.
